# Sprite sheet credits — `godot/art/sheets/`

## `lantern_flame.png`

- **Source:** generated by code, not downloaded: `make_lantern_flame_sheet.gd` in this folder.
  The assignment allows sheets written by code ("commit the code"). The PNG as committed is the
  original; the script reproduces it byte for byte (it reports "unchanged, not written").
- **Author:** the script was written by Claude Code (Claude Opus 5.5) on 2026-11-22. Zhaohui Li
  chose to generate the sheet by code instead of using a course or downloaded sheet (the course
  sprite set's path and licence were placeholders in the handout and the set could not be found).
- **Licence:** MIT, the repository's licence (`LICENSE`). No third-party art, model or reference
  image was used; no generative model was used.
- **Date checked:** 2026-11-22.
- **Format:** 48 × 32 px RGBA, cell 12 × 16 px, grid 4 × 2 (`hframes` 4, `vframes` 2), 8 cells,
  no padding or margin. Cell n is column n % 4, row n / 4, i.e. `Sprite2D.frame` n. Drawn 1:1 in
  the 640 × 360 viewport. The flame base is at (6, 15) in every cell.
